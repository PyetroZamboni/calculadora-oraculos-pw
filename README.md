# Calculadora de Oráculos Perfect World

Calculadora web gratuita para níveis 70 a 105.

## Personalize conforme o servidor

- XP concedida por Oráculo (padrão: 103.000 XP)
- Oráculos recebidos a cada 10 Sortes PW (padrão: 2)
- Preço de cada Sorte PW (padrão: 28)

Os valores são recalculados instantaneamente. As configurações são salvas somente no navegador de cada jogador.

## Site público

Após habilitar GitHub Pages em **Settings → Pages → Build and deployment → Deploy from a branch**, escolha **main** e **/(root)**.
